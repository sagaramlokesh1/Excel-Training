# 📗 Excel Training – Day by Day Learning

## 📌 About This Repository

This repository documents my day-by-day Microsoft Excel learning journey.

It contains practice files, exercises, formulas, functions, data-cleaning
techniques, PivotTables, charts, dashboards, and business-oriented Excel
analysis.

The goal is to build strong Excel skills for Data Analyst, Business Analyst,
MIS Analyst, and Reporting roles.

---

## 🎯 Learning Objectives

- Learn Excel from fundamentals to advanced concepts
- Practice formulas and functions
- Clean and transform raw datasets
- Perform data analysis
- Create PivotTables and PivotCharts
- Build interactive dashboards
- Automate repetitive tasks
- Develop business reporting and MIS skills
- Solve real-world data analysis problems

## Day 02 – Basic Formulas

Functions:
- SUM()
- AVERAGE()
- MIN()
- MAX()
- COUNT()
- COUNTA()
- ROUND()

Example:

    =SUM(B2:B10)
    =AVERAGE(B2:B10)
    =MAX(B2:B10)

---

## Day 03 – Logical Functions

Topics:
- IF()
- AND()
- OR()
- NOT()
- Nested IF
- IFERROR()

Example:

    =IF(C2>=50,"Pass","Fail")

    =IF(AND(B2>=50,C2>=50),"Eligible","Not Eligible")

---

## Day 04 – Conditional Functions

Functions:
- COUNTIF()
- COUNTIFS()
- SUMIF()
- SUMIFS()
- AVERAGEIF()
- AVERAGEIFS()

Example:

    =COUNTIF(B:B,"Completed")

    =SUMIF(A:A,"South",C:C)
